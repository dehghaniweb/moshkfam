# مشکفام فارس — نسخه B (وب + تلگرام + Android PWA)

این نسخه بر پایه پروژه قبلی ساخته شده است و موارد زیر را اضافه می‌کند:

- اصلاح فاصله متن داخل کارت محصولات، مخصوصاً فاصله از راست/بالا/پایین.
- ورود نماینده با نام کاربری و رمز عبور در وب و Android.
- نگهداری نشست ورود تا ۳۰ روز؛ رمز عبور خام در مرورگر یا دیتابیس ذخیره نمی‌شود.
- قیمت اختصاصی هر نماینده همچنان از دیتابیس خوانده می‌شود.
- ثبت سفارش/یادداشت فقط بعد از ورود مجاز است.
- پیام خطای دقیق برای مشخصات ورود تعریف‌نشده.
- افزودن و حذف محصول از پنل مدیریت.
- افزودن، ویرایش، غیرفعال و حذف نماینده از پنل مدیریت.
- تغییر رمز نماینده از پنل مدیریت.
- ویرایش نام شرکت، تلفن، آدرس و متن پایین صفحه از پنل مدیریت.
- لوگوی ارائه‌شده در سایت، favicon و PWA استفاده شده است.
- `manifest.json` و Service Worker برای نصب روی Android اضافه شده‌اند.

## فایل‌های مهم

- `index.html` — صفحه اصلی
- `style.css` — ظاهر
- `app.js` — منطق وب/تلگرام/PWA و ورود
- `worker.js` — Cloudflare Worker و API
- `schema.sql` — تغییرات دیتابیس و ۶ کاربر اولیه
- `manifest.json` — مشخصات نصب Android
- `service-worker.js` — پوسته آفلاین PWA
- `images/logo.png` — لوگوی اصلی
- `icons/` — آیکون‌های نصب و favicon

## راه‌اندازی دیتابیس

1. وارد Supabase شوید.
2. SQL Editor را باز کنید.
3. کل محتوای `schema.sql` را اجرا کنید.
4. شش کاربر اولیه ساخته می‌شوند؛ رمز همه در شروع `1234` است. بعد از تست، از پنل مدیریت رمزها را تغییر دهید.

## Cloudflare Worker

`worker.js` جدید را جایگزین Worker فعلی کنید و متغیرهای قبلی مثل:

- `SUPABASE_SECRET_KEY`
- `BOT_TOKEN` یا `TELEGRAM_BOT_TOKEN`
- `ADMIN_TELEGRAM_USER_ID`
- `WEBAPP_URL`
- سایر متغیرهای فعلی پروژه

را حفظ کنید.

## وب و Android

محتویات این پوشه را روی همان هاست قبلی قرار دهید. برای نصب PWA، سایت باید با HTTPS باز شود. در Chrome Android گزینه «Install app / افزودن به صفحه اصلی» قابل استفاده خواهد بود.

## تلگرام

تلگرام همچنان با `initData` خودش احراز هویت می‌شود و پنل مدیریت برای مدیر تلگرام باقی می‌ماند. مدیریت کاربران، محصولات، قیمت‌های اختصاصی و اطلاعات شرکت را می‌توان از همان پنل انجام داد.

## نکته امنیتی

رمزهای اولیه عمداً ساده انتخاب شده‌اند تا تست راحت باشد. بعد از اولین تست، برای هر نماینده رمز جداگانه و قوی تعیین کنید.
