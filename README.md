# مشکفام فارس — نسخه تولیدی A

این نسخه بر پایه فایل‌های فعلی پروژه ساخته شده و رابط کاربری و Worker را برای ساختار جدید آماده می‌کند.

## ساختار
- دسته‌بندی‌ها به صورت دایره‌ای نمایش داده می‌شوند.
- کل کارت محصول قابل کلیک است و دکمه «مشاهده مشخصات» حذف شده است.
- جزئیات محصول شامل تصویر، مشخصات، قیمت، ویدئو و در انتهای صفحه کاتالوگ است.
- قیمت اختصاصی مشتری از Worker دریافت می‌شود.
- پنل مدیریت برای قیمت پایه، تصویر، ویدئو و کاتالوگ آماده است.
- هنگام جایگزینی یا حذف تصویر/ویدئو/کاتالوگ، فایل قبلی در همان bucket داخل `old/` آرشیو می‌شود. فایل اصلی فعلی جایگزین یا از محصول خارج می‌شود.
- پیام `/start` نام کاربر را شخصی‌سازی می‌کند و مدیر/مشتری را بر اساس Telegram ID تشخیص می‌دهد.

## استقرار
1. محتوای پوشه `moshkfam-main` را روی GitHub Pages قرار دهید.
2. فایل `worker.js` را در Cloudflare Worker فعلی جایگزین کنید.
3. متغیرهای قبلی Worker مانند `SUPABASE_SECRET_KEY`، `BOT_TOKEN`، `ADMIN_TELEGRAM_USER_ID` و `WEBAPP_URL` را حفظ کنید.
4. در Supabase لازم نیست برای قابلیت آرشیو فعلی SQL جدیدی اجرا شود؛ آرشیو در Storage انجام می‌شود.
5. بعد از Deploy، در تلگرام `/start` را بزنید و سپس «🚀 ورود به سامانه» را باز کنید.

## نکته
پوشه `old/` به صورت خودکار ساخته می‌شود؛ در Storage لازم نیست دستی ایجاد شود.
